<h2>❓ Troubleshooting</h2>

<h3>Octop won’t open</h3>
- Make sure your Windows version is updated
- Try right-clicking the Octop icon and selecting <strong>"Run as administrator"</strong>
- Restart your computer and try again



<h3>Octop is slow</h3>
- Close other heavy programs to free up memory
- In settings, reduce the number of agents used for tasks
- Check that you have enough free disk space (at least 2 GB recommended)



<h3>I forgot my password</h3>
- Use the "Forgot Password" link on the login screen
- If that doesn’t work, you can reset Octop entirely by uninstalling and reinstalling (you will lose your settingsand memory)
